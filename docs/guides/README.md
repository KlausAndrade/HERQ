# HERQ Guides

This directory contains comprehensive guides for setting up, configuring, and using the HERQ fitness application.

## 📚 Available Guides

### 🔐 User Isolation & Security
- **`USER_ISOLATION_SETUP_GUIDE.md`** - Complete guide for setting up user data isolation
- **`USER_ISOLATION_TESTING_GUIDE.md`** - Testing procedures for user isolation

### 🌐 Internationalization
- **`MULTI_LANGUAGE_IMPLEMENTATION_SUMMARY.md`** - Multi-language support implementation
- **`TRANSLATION_TESTING_GUIDE.md`** - Testing procedures for translations

### 🎨 UI & Design
- **`MULTI_LINE_BUTTON_GUIDE.md`** - Guide for multi-line button implementation
- **`LOGO_SETUP.md`** - Logo setup and branding guidelines

### 🏋️ Exercise System
- **`EXERCISE_VARIANT_SYSTEM.md`** - Exercise variant system documentation

### 🔒 Security & Privacy
- **`EMAIL_PROTECTION_GUIDE.md`** - Email protection and privacy guidelines

## 🚀 Quick Start

### For Developers
1. Start with the **User Isolation Setup Guide** if you need multi-user support
2. Check the **Multi-Language Implementation** for internationalization
3. Review **Exercise Variant System** for exercise management

### For Administrators
1. Follow the **User Isolation Setup Guide** for production deployment
2. Use the **Testing Guide** to verify everything works correctly
3. Check **Email Protection Guide** for privacy compliance
