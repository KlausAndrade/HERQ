# Background Rest Timer - User Guide

## What's New? 🎉

Your rest timer now appears in the **notification bar** and continues running even when you minimize the app or use other apps on your phone!

## How It Works

### During Your Workout

1. **Complete a set** as normal
2. **Tap "Log Set"** button
3. **Rest timer starts** (e.g., 90 seconds)
4. 🔔 **Notification appears** showing countdown

### What You'll See

#### In the Notification Bar
```
⏱️ Rest Timer
Time remaining: 01:30

[Progress bar filling up]
```

The notification updates every second:
- `01:30` → `01:29` → `01:28` ... → `00:05` → `00:04` ... → `00:00`

#### When Timer Completes
```
⏰ Rest Timer Complete!
Time to start your next set! 💪
```
- Your phone vibrates
- Sound notification plays
- Ready to start next set!

## Settings & Permissions

### First Time Setup

**iOS:**
1. First time timer starts
2. iOS asks: "Allow GymAI to send notifications?"
3. Tap **"Allow"**
4. Notifications enabled! ✅

**Android:**
1. First time timer starts
2. Android may ask for notification permission
3. Tap **"Allow"**
4. Notifications enabled! ✅

### If Notifications Don't Appear

**iOS:**
1. Go to **Settings** app
2. Scroll to **GymAI**
3. Tap **Notifications**
4. Enable **"Allow Notifications"**
5. Restart app

**Android:**
1. Go to **Settings** app
2. Tap **Apps** → **GymAI**
3. Tap **Notifications**
4. Enable notifications
5. Restart app

### Managing Notifications

**Want to disable?**
- Use system settings (above)
- App will still work, just no notifications
- Timer widget in app still shows countdown

**Want different settings?**
- Future update will add in-app controls
- For now, use system notification settings

## Troubleshooting

### Issue: Notification doesn't show
**Try this:**
1. Check notification permissions (see above)
2. Restart app
3. Try logging a set again
4. Check Do Not Disturb mode is off

### Issue: Notification shows but doesn't update
**Possible reasons:**
- Battery saver mode (limits background apps)
- iOS background restrictions
- Phone is very low on battery

**Try this:**
1. Keep app in foreground during timer
2. Disable battery saver mode
3. Charge phone

### Issue: No vibration when timer completes
**Check:**
- Phone not in silent mode
- Vibration enabled in system settings
- Test on real device (simulators don't vibrate)

### Issue: No sound when timer completes
**Check:**
- Volume is turned up
- Not in Do Not Disturb mode
- Notification sounds enabled
- Check system notification settings

### Issue: Timer is inaccurate
**This shouldn't happen, but if it does:**
1. Stop timer
2. Force close app
3. Reopen app
4. Start new timer
5. Report bug if it continues
