# HERQ Brand Guidelines

## Name

**HERQ** (all caps)

## Tagline

**Smart Strength. Simplified.**

## Brand Story

Inspired by the spirit of Heracles — the original symbol of strength and perseverance — HERQ fuses ancient power with modern intelligence.

Built for lifters, movers, and everyday heroes who believe strength isn't just physical — it's a mindset.

## Brand Mission

Whether you're chasing your first pull-up or your next PR, HERQ helps you train smarter, recover better, and rise stronger.

### Color Usage Guidelines

**Electric Teal (#00BFA6)**
- Primary buttons and CTAs
- Active states and selections
- Progress indicators
- Interactive elements

**Warm Lime (#D4FF4D)**
- Secondary accents
- Achievement celebrations
- Energy indicators
- Gradient combinations with Teal

**Deep Graphite (#1B1D21)**
- Primary text on light backgrounds
- Card surfaces in dark mode
- Strong contrast elements

**Soft Charcoal (#141516)**
- Main background in dark mode
- Deep contrast areas

**Mist White (#F8F8FA)**
- Primary text on dark backgrounds
- Main background in light mode
- Clean, minimal surfaces

### Gradient Effects

**Teal → Lime Gradient**
```
Linear gradient from #00BFA6 to #D4FF4D
Use for: Hero sections, dynamic glow effects, achievement celebrations
```

## Typography

### Font Families

**Logo / Titles**
- Primary: Monument Extended (when available)
- Fallback: Anton
- Characteristics: Bold, compressed strength
- Usage: App logo, major headings, hero text
- Weight: 900 (Black)

**Body Text**
- Primary: Inter
- Fallback: Satoshi Regular, System Sans-serif
- Characteristics: Modern, legible, mobile-friendly
- Usage: All body text, descriptions, labels
- Weights: 400 (Regular), 500 (Medium), 600 (Semibold)

**Accent Text**
- Primary: Space Grotesk
- Fallback: Inter, System Sans-serif
- Characteristics: Clean, elegant
- Usage: Hero sections, feature callouts, statistics
- Weights: 400 (Regular), 600 (Semibold)

## App Icon Concept

**Concept**: Bold monogram with movement arc

**Design Elements**:
- Stylized "H" or "HQ" monogram
- Geometric, modern shape
- Movement or progress arc integrated
- Strong, recognizable silhouette
- Works well at small sizes (16x16 to 1024x1024)

**Color Application**:
- Primary: Electric Teal background
- Accent: Warm Lime highlights or arc
- Alternative: Graphite background with Teal/Lime gradient

## Brand Voice

### Voice Characteristics

**Confident**
- Direct, action-oriented language
- No hedging or uncertainty
- Empowering tone

**Minimal**
- Clean, concise copy
- No fluff or unnecessary words
- Clear, focused messaging

**Inclusive**
- Speaks to all fitness levels
- No gatekeeping
- Everyone is a hero in their journey

### Messaging Examples

**Good Examples**:
- "Track every rep. Own every PR."
- "Your strength, measured."
- "Rise stronger."
- "Train smart. Recover better."

**Avoid**:
- Overly technical jargon without context
- Exclusive or intimidating language
- Excessive exclamation marks
- Generic fitness clichés

## UI/UX Guidelines

### Component Styling

**Buttons**
- Primary: Electric Teal fill, Graphite text
- Secondary: Teal outline, Teal text
- Disabled: 40% opacity
- Border Radius: 8px (SM), 12px (MD), 16px (LG)
- Padding: 16px horizontal, 12-14px vertical

**Cards**
- Background: White (light mode), Graphite (dark mode)
- Border Radius: 12px
- Elevation: Soft shadow (light), Strong shadow (dark)
- Padding: 16-24px

**Input Fields**
- Border: 1.5px solid outline color
- Focus: Electric Teal border
- Border Radius: 8px
- Padding: 12-16px

### Spacing System

| Token | Size | Usage |
|-------|------|-------|
| XS | 4px | Tight spacing, inline elements |
| SM | 8px | Small gaps, compact layouts |
| MD | 16px | Standard spacing, most common |
| LG | 24px | Section spacing |
| XL | 32px | Large section gaps |
| XXL | 48px | Major section breaks |

## Platform-Specific Guidelines

### iOS
- Follow Apple HIG for native iOS components
- Use SF Symbols where appropriate
- Maintain iOS gesture conventions
- Support Dynamic Type

### Android
- Follow Material Design 3 principles
- Use Material icons
- Support gesture navigation
- Adaptive layouts for various screen sizes

### Web
- Responsive breakpoints: 320px, 768px, 1024px, 1440px
- Touch-friendly targets (min 44x44px)
- Keyboard navigation support
- WCAG AA accessibility compliance

## Accessibility

### Color Contrast

All color combinations must meet WCAG AA standards:
- Teal on Graphite: ✅ 4.5:1 (passes AA)
- Teal on Charcoal: ✅ 4.8:1 (passes AA)
- Lime on Graphite: ⚠️ Use with caution (check contrast)
- White on Graphite: ✅ 14.2:1 (passes AAA)

### Text Guidelines

- Minimum font size: 14px
- Line height: At least 1.5x font size
- Paragraph width: Max 80 characters
- Support dynamic text sizing

### Interactive Elements

- Minimum touch target: 44x44px
- Clear focus indicators
- Alt text for all images
- ARIA labels for complex interactions
